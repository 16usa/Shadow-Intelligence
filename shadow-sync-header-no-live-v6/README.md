# Shadow SYNC Header No LIVE v6

This patch only removes the global **● LIVE** status from the right side of the `/sync` header.

The header becomes:

**SYNC + logo** — left  
**X** — exactly centered  
**right side** — empty

Everything else stays unchanged.

## Install

```bash
unzip -o shadow-sync-header-no-live-v6.zip
bash shadow-sync-header-no-live-v6/install.sh
```

No restart is performed automatically.
