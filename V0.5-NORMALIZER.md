# Shadow Intelligence v0.5 — Transaction Normalizer

This release fixes the v0.4 live-wallet parser so one Solana transaction is represented as one canonical user-facing trade whenever Helius provides a decoded swap event.

## What changes

- Uses Helius `events.swap` as the primary source for SWAP transactions.
- Collapses intermediate token-transfer legs into one canonical BUY / SELL / SWAP event.
- A generic token transfer is no longer mislabeled as a BUY just because the wallet paid SOL network fees.
- Keeps Pump.fun/PumpSwap detection and token market enrichment.
- Adds exponential retry/backoff for Helius / RPC HTTP 429 and transient 5xx errors.
- Incremental Helius history can page through up to 500 new transactions to reduce missed activity on busy wallets.
- v0.4 wallet activity is preserved in `wallet_activity_v04_archive`, then the live activity view is rebuilt using the corrected normalizer.
- Existing users, owner role, entities, wallets, avatars, evidence, social posts, chat, DMs and settings are preserved.
- Machine-generated v0.4 chain incidents/correlations are rebuilt so old parser mistakes do not affect Risk Score.
