Shadow Intelligence — Tokens Period + Age v2.6.1

Use this instead of v2.6.0.

Filters:
1M | 5M | 1H | 6H | 24H | Age | MC

Age sorts youngest token/market first. It uses the earliest known market/pair creation timestamp from DexScreener and does NOT use when Shadow noticed the token.

Install:
cd ~/workspace && rm -rf shadow-tokens-period-age && unzip -o Shadow-Tokens-Period-Age-v2.6.1.zip -d shadow-tokens-period-age && bash shadow-tokens-period-age/install.sh

Then restart the main Shadow/Replit app once.
