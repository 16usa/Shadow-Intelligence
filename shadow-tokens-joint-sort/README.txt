Shadow Tokens Joint Sort v2.6.8

All three criteria work together at the same time.

Controls:
1M | 5M | 1H | 6H | 24H | Age ↓/↑ | MC ↓/↑

Priority:
1. Selected time-period price change
2. Token age
3. Market cap

Age:
- Age ↓ = youngest first
- Age ↑ = oldest first

MC:
- MC ↓ = highest market cap first
- MC ↑ = lowest market cap first

The chosen Age and MC directions remain active when you switch 1M/5M/1H/6H/24H.

Install:
cd ~/workspace && rm -rf shadow-tokens-joint-sort && unzip -o Shadow-Tokens-Joint-Sort-v2.6.8.zip -d shadow-tokens-joint-sort && bash shadow-tokens-joint-sort/install.sh

No server restart required.
