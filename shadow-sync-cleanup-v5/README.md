# Shadow SYNC Cleanup v5

This patch makes only two UI changes to `/sync`:

- Removes the **FUSION MARK** chip from the hero.
- Removes **LEADER ACTIVITY** above **Live signals**, leaving **Live signals** as the only heading.

It does **not** change:
- `ONE LEADER · N CONNECTED`
- wallet counters
- `START COPYING`
- `STOP COPYING`
- copy settings
- notifications
- the header logo / X / LIVE

## Install

```bash
unzip -o shadow-sync-cleanup-v5.zip
bash shadow-sync-cleanup-v5/install.sh
```

No restart is performed automatically.
