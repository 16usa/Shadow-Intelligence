# Shadow SYNC Text Brand v8

This patch changes only the left side of the `/sync` header:

- Removes the current logo image.
- Leaves only **SYNC** as text.
- Uses the same **IBM Plex Mono** font already used across the page.

Everything else stays unchanged.

## Install

```bash
unzip -o shadow-sync-text-brand-v8.zip
bash shadow-sync-text-brand-v8/install.sh
```

No restart is performed automatically.
