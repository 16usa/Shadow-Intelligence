# Shadow SYNC Three Black Levels v10

Adds restrained depth using only three near-black surface levels.

- Page: `#000000`
- Level 1: `#070707`
- Level 2: `#0D0D0D`
- Level 3: `#151515`

Used selectively on:
- Inputs
- Quick amount buttons
- Badges
- Secondary buttons
- Authorization panel
- Sheet / owner surfaces

Everything else stays black.

## Install

```bash
unzip -o shadow-sync-three-black-levels-v10.zip
bash shadow-sync-three-black-levels-v10/install.sh
```

No restart is performed automatically.
