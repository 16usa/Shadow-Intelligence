Shadow Intelligence — Top 24H Movers bell-row layout v2.5.2

This places the 24H mover cards on the SAME horizontal row as the notification bell.

- Bell stays visible at far right.
- Movers start immediately to the left of the bell.
- First mover is on the bell/right side.
- Cards are 50px high, matching the bell button.
- Separate 24H MOVERS heading is hidden for a clean single-row layout.
- No backend changes; no server restart required.

Install:
cd ~/workspace && rm -rf shadow-top-24h-bell && unzip -o Shadow-Top-24H-Bell-Row-v2.5.2.zip -d shadow-top-24h-bell && bash shadow-top-24h-bell/install.sh
