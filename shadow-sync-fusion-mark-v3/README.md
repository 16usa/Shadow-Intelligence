# Shadow SYNC Fusion Mark v3

Adds the chosen **Option 1 / Fusion Mark** to the `/sync` page.

## What changes
- Left header brand becomes **Fusion Mark + SYNC**
- Hero gets a small **FUSION MARK** branded chip
- Browser tab favicon becomes the SYNC mark
- Preserves the centered **X** icon and the single global **● LIVE** status

## Install
Run from the Shadow-Intelligence repository root:

```bash
unzip -o shadow-sync-fusion-mark-v3.zip
bash shadow-sync-fusion-mark-v3/install.sh
```

No restart is performed automatically.
