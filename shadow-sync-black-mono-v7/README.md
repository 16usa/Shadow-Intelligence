# Shadow SYNC Black Mono v7

This patch changes only the visual system of `/sync`:

- Pure black `#000000` background
- `0.5px` separator lines
- `IBM Plex Mono` across the whole page
- Removes decorative background glow
- Keeps green/red functional accents

## Install

```bash
unzip -o shadow-sync-black-mono-v7.zip
bash shadow-sync-black-mono-v7/install.sh
```

No restart is performed automatically.
