# Shadow SYNC Header Cleanup v2

Installs the cleaner SYNC header and removes repeated live-status labels.

Install from the Shadow-Intelligence repository root:

```bash
unzip -o shadow-sync-header-cleanup-v2.zip
bash shadow-sync-header-cleanup-v2/install.sh
```

No restart is performed automatically.

The centered X icon currently uses `href="#"`. When you have the X profile URL, replace that value in `public/sync.html`.
